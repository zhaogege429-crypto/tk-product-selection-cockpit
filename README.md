# TK选品指挥舱

一个面向 TikTok 电商团队的 AI 选品研判工具。用户输入产品名称、类目、价格带、卖点、人群和补充背景后，系统会基于 TikTok 电商操盘逻辑输出结构化判断，帮助团队快速回答三个问题：

1. 这个产品适不适合在 TikTok 生态里卖。
2. 更适合短视频、直播、达人分销，还是不建议做。
3. 核心卖点、行动建议和风险点分别是什么。

## 本地运行

1. 安装依赖：`npm install`
2. 配置环境变量：基于 `.env.example` 新建 `.env.local`，填入 `GEMINI_API_KEY`
3. 启动开发环境：`npm run dev`
4. 打开浏览器访问：`http://localhost:3000`

## 当前实现概览

- 前端技术栈：React 19、TypeScript、Vite、Tailwind CSS 4
- AI 能力：前端直接调用 Gemini 模型生成结构化 JSON 报告
- 当前输入字段：产品名称、类目、价格带、核心卖点、使用场景与人群、补充信息
- 当前输出模块：研判结论、适配性分析、推荐路径、核心卖点、行动建议、缺失信息提醒

## 当前限制

- 目前没有后端，API Key 由用户在前端配置并保存在浏览器 `localStorage`
- 目前没有历史报告、批量分析、团队协作、权限控制、导出能力
- 目前不支持直接解析商品链接、图片、视频或外部电商数据
