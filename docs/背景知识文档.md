# 背景知识文档

## 1. 文档目的

本文档用于沉淀 `TK选品指挥舱` 背后的业务判断基础，帮助产品、研发、运营和提示词维护者理解：为什么这个产品不是普通的“商品分析器”，而是一个围绕 TikTok 电商选品逻辑建立的判断系统。

## 2. 什么是 TikTok 选品

TikTok 选品的核心不是“这个货有没有市场”，而是“这个货能不能被内容高效卖出去”。因此，一个在传统货架电商表现不错的产品，不一定适合 TikTok；反过来，一个在线下或传统电商不算强势的产品，也可能因为内容展示力强而在 TikTok 爆发。

## 3. TikTok 选品的核心判断框架

### 3.1 内容可卖性

看的是产品是否适合被短视频或直播展示出来。

重点关注：

1. 有没有明显展示感。
2. 能不能做前后对比。
3. 有没有结果感、反差感、惊喜感。
4. 前 3 秒能不能抓住注意力。

典型适合内容表达的产品往往具有以下特征：

1. 使用效果直观。
2. 痛点容易理解。
3. 演示动作简单。
4. 不需要太多教育成本。

### 3.2 成交可转化性

看的是用户看到内容后，是否容易理解卖点并快速下单。

重点关注：

1. 是否能一句话说清卖点。
2. 决策门槛是否低。
3. 是否适合冲动消费。
4. 价格和感知价值是否匹配。
5. 售后复杂度是否可控。

### 3.3 流量可放大性

看的是这个产品是否适合被更多流量承接。

常见路径包括：

| 路径 | 适合情况 |
| --- | --- |
| 短视频自然流 | 展示感强、内容切入容易、适合快速测款 |
| 短视频付费投流 | 卖点明确、转化链路短、可用素材规模化 |
| 达人分销 | 卖点容易复制、达人好讲、佣金空间合理 |
| 直播带货 | 需要主播讲解承接、适合组合销售或现场演示 |
| 组合打法 | 既能靠内容起量，又需要直播或达人承接 |

### 3.4 风险可控性

看的是产品是否会在放量后带来明显经营问题。

常见风险包括：

1. 夸大宣传或功效宣称风险。
2. 侵权、专利、商标风险。
3. 尺码、肤感、效果因人而异导致退货高。
4. 物流破损、重量体积、时效问题。
5. 教育成本过高，视频讲不清，直播也难成交。

### 3.5 货盘角色判断

一个产品即使能卖，也不一定适合担当同一种角色。常见角色包括：

| 角色 | 说明 |
| --- | --- |
| 引流款 | 低门槛、好理解、容易拉新 |
| 爆款 | 展示感强，内容和流量都有爆发潜力 |
| 利润款 | 客单价或毛利较高，需要更强承接能力 |
| 直播福利款 | 更适合直播间制造氛围和停留 |
| 达人测款 | 适合先通过达人低成本验证 |

## 4. 为什么产品需要“明确分级”

在选品场景里，如果 AI 只说“可以试试”，对业务没有真实价值。因为团队真正需要的是拍板语言。所以当前产品把结论分成四档：

| 结论等级 | 含义 |
| --- | --- |
| 优先做 | 适配度高，值得优先投入资源验证 |
| 可以测试 | 有机会，但需要低成本验证 |
| 谨慎进入 | 有明显短板或风险，不宜重投入 |
| 不建议做 | 不符合 TikTok 生态逻辑或风险过高 |

## 5. 什么样的产品更容易适合 TikTok

通常更适合 TikTok 的产品有以下倾向：

1. 能演示、能对比、能制造视觉冲击。
2. 一句话能讲清楚它解决什么问题。
3. 价格不至于让用户长时间犹豫。
4. 用户看到内容后容易产生即时购买冲动。
5. 售后和履约相对可控。

## 6. 什么样的产品更容易不适合 TikTok

通常需要谨慎的产品包括：

1. 教育成本高，需要大量解释才能理解价值。
2. 使用效果高度因人而异，容易引发争议。
3. 强依赖品牌背书，没有内容表达空间。
4. 合规、功效、侵权风险高。
5. 物流和售后复杂，放量后容易失控。

## 7. 为什么“缺失信息提醒”是必要的

真实业务里，选品初期经常拿不到完整信息。如果工具因为信息不全直接拒答，会失去使用价值；但如果装作信息完整，又会误导决策。因此当前产品加入了“缺失字段 + 影响说明”机制，目的有两个：

1. 告诉用户当前结论是降级判断，不应被当成最终结论。
2. 指出下一步需要补什么信息，帮助团队继续推进。

## 8. 团队在使用该产品时应补充的关键信息

如果要提升判断质量，建议尽量补齐以下信息：

1. 真实售价带与目标市场。
2. 产品的核心痛点与使用前后差异。
3. 用户画像与主要消费场景。
4. 已有测品反馈、达人反馈或评论反馈。
5. 是否存在侵权、功效词、资质、物流限制等风险。

## 9. 本产品与传统商品分析工具的差异

| 维度 | 传统商品分析 | TK选品指挥舱 |
| --- | --- | --- |
| 判断核心 | 市场需求、供给、价格竞争 | 内容可卖性、转化、放量、风险 |
| 输出形态 | 数据、报表、竞品分析 | 结构化业务判断 |
| 适用场景 | 货架电商或通用分析 | TikTok 电商选品和打法判断 |
| 目标用户 | 运营、采购、分析师 | 选品、操盘、投手、老板 |

## 10. 使用边界

这个产品适合做“第一轮选品判断”，不适合直接替代以下工作：

1. 平台真实数据验证。
2. 投放 ROI 验证。
3. 合规审核。
4. 供应链与履约能力评估。

## 11. 背景知识结论

`TK选品指挥舱` 的本质是把 TikTok 电商一线操盘经验中的判断语言，整理成一个 AI 可执行、团队可复用的结构化框架。它最大的价值不是“回答得像 AI”，而是“回答得像一个真正懂 TikTok 卖货的人，并且能被团队拿来直接讨论和决策”。
